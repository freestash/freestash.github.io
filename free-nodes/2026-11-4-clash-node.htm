第一章：Shadowrocket到底是什么？为什么偏偏是它？

在正式动手之前，我们先花两分钟搞懂这个工具的本质。Shadowrocket，中文圈常称“小火箭”，是一款专为iOS和iPadOS设计的网络代理客户端。它不像某些“全家桶”软件那样臃肿，而是把核心功能做到极致——支持HTTP、HTTPS、SOCKS5、Shadowsocks、VMess、Trojan等多种主流代理协议，这意味着你几乎可以连接任何类型的代理服务器。

但更关键的是它的“智能分流”能力。简单说，它可以让你的国内流量直连（不经过代理，速度不受影响），而国外流量自动走代理（突破封锁）。这种精细化的路由规则，是很多同类工具不具备的。再加上它原生适配iOS系统，耗电低、后台稳定、支持小组件快捷开关，用起来就像苹果自家出品一样顺滑。

至于为什么售价是10元？这其实是开发者的定价策略——用极低的门槛吸引用户，靠口碑传播。相比某些订阅制工具每月几十元的费用，Shadowrocket的一次性买断价格，简直是网络工具界的“良心之作”。当然，它偶尔会因政策原因在部分地区的App Store下架，所以如果你现在能在商店里看到它，别犹豫，先拿下再说。

很多人在第一步就卡住了：为什么我在App Store搜索“Shadowrocket”搜不到？这里有一个关键前提：Shadowrocket只在部分国家和地区的App Store上架（比如美区、港区）。如果你用的是国区Apple ID，搜索结果里只会出现一堆山寨的“Shadow Rocket”或“小火箭加速器”。

正确下载姿势分两步走

第一步：准备一个可用的海外Apple ID。 你可以自己注册一个美区或港区账号（流程不复杂，网上教程很多），也可以在某宝上买一个现成的（务必选择“只登录App Store，不登录iCloud”的账号，安全第一）。登录App Store后，搜索“Shadowrocket”，你会看到一个火箭图标的应用，价格通常显示为$0.99或HK$8.00，折合人民币约10元。

第二步：支付问题。 如果你没有绑定海外信用卡，也别慌。最简单的方法是购买美区或港区的App Store礼品卡，充值到你的海外账号里，再完成购买。整个过程5分钟搞定。记住：千万不要用国区账号去搜，搜不到是正常的，不是你手机的问题。

安装完成后，桌面上那个灰黑色火箭图标，就是你的新伙伴了。别急着打开，我们接下来进入最核心的环节——配置。

第三章：配置不求人——从零开始搭建你的第一条代理线路

下载只是开始，配置才是灵魂。很多用户买了Shadowrocket后，看着空荡荡的首页一脸茫然。别担心，跟着我的步骤走，十分钟内你就能跑起来。

3.1 获取服务器信息

首先，你需要一个代理服务器。常见来源有两个：一是自己购买VPS搭建（适合技术玩家），二是从机场（代理服务商）购买订阅链接（适合普通用户）。如果你已经有服务器或订阅，请准备好以下信息：服务器地址、端口、密码、加密方式（或直接复制订阅URL）。

3.2 两种添加方式

方式一：手动添加。 点击首页右上角的“+”号，选择“类型”（比如Shadowsocks），然后依次填入服务器地址、端口、密码、加密方式。如果服务器支持，建议开启“混淆”和“协议”选项，能提升抗封锁能力。

方式二：订阅导入（强烈推荐）。 如果你从机场买了服务，他们通常会提供一个类似https://xxx.com/subscribe?token=xxxx的链接。复制这个链接，回到Shadowrocket首页，点击右上角的“+”号，选择“类型”里的“Subscribe”，粘贴链接，点击“保存”。应用会自动拉取所有节点列表，你只需要在首页滑动选择其中一个即可。

3.3 核心设置：全局路由模式

这是Shadowrocket最强大的地方。首页下方有三个选项：

  • 配置：这里可以选择别人写好的规则文件（后面细说）。
  • 全局路由：点进去有三个模式——“代理”（所有流量走代理，适合临时用）、“配置”（按规则分流，推荐日常使用）、“直连”（所有流量不走代理）。
  • 延迟测试：点击每个节点旁边的数字，可以测出该节点的响应速度，选数字最小的那个，通常就是最快的。

我的建议是：日常选择“配置”模式，配合一个优质的规则文件，让国内网站直连、国外网站走代理，既快又省流量。

3.4 启用连接

完成上述设置后，回到首页，把顶部的开关从“关闭”拨到“开启”。第一次开启时，iOS会弹出“允许添加VPN配置”的提示，点击“允许”，输入你的设备密码。看到开关变成绿色，状态栏出现VPN图标，恭喜你——你已经成功翻越了网络围墙。

第四章：进阶技巧——让你的Shadowrocket更好用

很多人的Shadowrocket止步于“能连上”，但如果你愿意多花十分钟，它的体验可以再上一个台阶。

4.1 导入优质规则文件

默认的“配置”模式虽然能用，但分流不够精细。我推荐你到GitHub上搜索“shadowrocket 规则”或“lhie1 规则”，找一个star数高的规则文件。下载后，用Shadowrocket打开，选择“使用Shadowrocket导入”，然后在“配置”里选中它。好的规则文件能让你访问Google、YouTube时走代理，而访问淘宝、B站时直连，甚至能过滤掉大部分广告。

4.2 开启“Tun模式”与“IPv6”

在“设置”->“高级设置”里，打开“Tun模式”。这个功能可以让所有系统流量（包括那些不遵守系统代理的App）都经过Shadowrocket，极大提升兼容性。同时，如果你的网络环境支持IPv6，可以在“设置”里开启“IPv6”，访问某些纯IPv6网站时速度会有惊喜。

4.3 小组件与快捷指令

长按桌面空白处，点击左上角的“+”号，搜索Shadowrocket，添加它的桌面小组件。这样你不需要打开App，就能在桌面一键切换节点或查看当前连接状态。更进一步，你可以在“快捷指令”App里创建自动化——比如“当连接Wi-Fi时关闭代理，离开时自动开启”，实现全自动切换。

4.4 定期更新订阅

机场的节点会不定期变动。在Shadowrocket首页，点击右下角的“设置”图标，找到“订阅”一栏，开启“自动更新”（建议设置为24小时）。这样每次打开App，它都会在后台静默更新节点列表，保证你永远有可用的线路。

第五章：日常使用避坑指南——这些细节决定成败

工具是死的，人是活的。以下几个常见问题，你大概率会遇到。

问题一：连上了但打不开网页？ 先别急着重启。检查全局路由是否选的是“配置”模式，如果是“代理”模式且你的节点本身速度很慢，就会这样。试着切换一个节点，或者用“延迟测试”功能找找最快节点。

问题二：速度忽快忽慢？ 这是机场的常态，尤其是晚高峰。建议准备两三个不同运营商的机场作为备用，在Shadowrocket里分别导入订阅，哪个快用哪个。另外，开启“混淆”有时能突破运营商的QoS限制。

问题三：耗电严重？ 如果你长时间开着Shadowrocket，确实会多耗一点电。建议在“设置”->“通用”里开启“仅Wi-Fi连接”，这样在移动网络下不会自动连接代理，能省不少电。当然，如果你流量充足，也可以忽略这条。

问题四：隐私安全吗？ Shadowrocket本身不记录你的任何流量日志，但你的机场服务商可以看到。所以，选择机场时务必选那些承诺“不记录日志”的。另外，永远不要在通过代理访问网站时输入银行卡密码等敏感信息，除非你明确知道该网站是安全的。

FAQ

Shadowrocket 节点测速结合策略组的作用？
Shadowrocket 定期测速节点延迟和丢包率，并结合策略组自动选择最佳节点。保证网页、视频和游戏流量走低延迟节点，提高访问速度和连接稳定性。
Mihomo 是否比 Clash Meta 更快？
Mihomo 是 Clash Meta 的优化分支，采用最新 Go 语言版本编译并针对多线程性能进行了改进。整体运行效率略高，特别是在多节点切换和 DNS 分流方面表现更流畅。
Hysteria2 的多路复用功能有哪些优势？
多路复用允许多个请求共享同一 QUIC 连接，减少握手次数和延迟。高并发情况下可以提升吞吐量和稳定性，特别适合短连接频繁请求的应用，如游戏或即时通讯。
Clash 如何防止规则文件冲突导致分流异常？
合理组织规则顺序，将更具体的规则放在前面，通配规则放在末尾；使用 rule-providers 分离不同来源的规则，避免重复条目，并在变更后使用日志或 debug 模式检验分流是否按预期生效。
Mihomo 启动后 CPU 占用高，有哪些优化建议？
检查是否启用了大量日志或复杂脚本，关闭不必要的规则提供者与日志调试；在多核服务器上启用并发或调整线程数；更新到最新版本以获得性能优化，并监控是否有异常连接导致处理压力。
Clash 的 Rule Provider 功能是干什么的？
Rule Provider 是 Clash 的规则订阅机制，它可以通过远程 URL 自动更新分流规则文件。这样用户无需手动修改本地配置，就能保持规则同步更新，例如广告过滤或流媒体分流。
WinXray 的 PAC 模式如何应用？
PAC 模式根据规则自动判断流量是否走代理，无需手动切换节点。适合访问国内外混合网站环境，提高网络访问速度和稳定性，减少误操作导致的访问失败。
Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
Hysteria2 的 QUIC 协议相比 TCP 有什么优势？
QUIC 协议基于 UDP，减少了握手延迟，支持多路复用和拥塞控制优化。Hysteria2 利用 QUIC 提供更低延迟、更高稳定性的网络连接，尤其适合高延迟或丢包环境。
SSR 的混淆插件如何增强隐蔽性？
混淆插件可模拟正常协议特征，如 HTTP 或 TLS 流量，使 SSR 流量难以被检测。合理选择混淆方式和协议，可提升在高封锁环境下的长期稳定性和安全性。
