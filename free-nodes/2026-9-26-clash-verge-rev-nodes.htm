实操指南：从安装到配置的完整路径

第一步：获取与安装

  1. 下载：请务必前往 官方网站 或 GitHub Releases 页面下载对应操作系统（Windows / macOS / Linux）的最新版本安装包。切勿从第三方下载站获取，以防被植入恶意代码。
  2. 安装：以 Windows 为例，解压后运行 clash-verge.exe 或 clash.exe。macOS 用户则需将 App 拖入“应用程序”文件夹。安装过程通常无特殊选项，一路 Next 即可。

第二步：核心配置——导入订阅与节点

这是最关键的一步。

  1. 获取订阅链接：从您的代理服务商处复制订阅地址。
  2. 导入配置：
    • 打开 Clash 100 Pro 界面，找到“配置”或“Profiles”标签页。
    • 选择“从 URL 导入”，粘贴订阅链接，点击下载。
    • 下载完成后，该订阅文件会出现在配置列表中，点击选中它，使其成为当前激活的配置文件。
  3. 更新与切换：订阅链接通常有有效期，建议定期点击“更新”按钮，以获取最新的节点信息。

第三步：开启代理与模式选择

  1. 启动系统代理：在主界面，将“系统代理”开关打开。此时，Clash 100 Pro 会自动接管您浏览器的网络请求。
  2. 选择代理模式：
    • 规则模式：这是最推荐的模式。它将根据您配置的规则自动判断流量走向，实现智能分流。
    • 全局模式：所有流量均走代理。适合访问某些未被规则覆盖的海外网站，但会拖慢国内网站访问速度。
    • 直连模式：所有流量均不走代理。相当于关闭了代理功能。

第四步：节点选择与测速

在“代理”或“Proxies”标签页，您会看到一组策略组（如 PROXY、GLOBAL、国内直连等）。点击策略组，可以展开其下的所有节点。建议先点击“测速”按钮，软件会自动对所有节点进行延迟测试，并排序。选择延迟最低（数值越小越快）的节点即可。

常见问题应急处理

  • 无法连接网络：首先检查系统代理是否开启；其次，尝试切换代理模式（如从“规则”切换到“全局”）；最后，检查节点是否失效，更换一个节点再试。
  • 速度极慢：可能是所选节点负载过高。建议测速后更换节点，或尝试 UDP 中继（如果支持）。
  • 部分网站打不开：多为规则误判所致。可尝试在配置文件中添加该域名的直连或代理规则，或暂时切换到全局模式判断是否为规则问题。
